# NEON DODGE — Vercel Ready

This is the browser version of the NEON DODGE arcade game.

## Stack
- HTML5 Canvas
- CSS
- JavaScript
- Web Audio API
- localStorage

No Python, Pygame, backend, API key, external image, or external game engine is required.

## Vercel
Put these files in the repository root:
- `index.html`
- `style.css`
- `game.js`

The project is a static site. Vercel does not need a build command.

Recommended Vercel settings:
- Framework Preset: Other
- Build Command: empty
- Output Directory: `.`
- Install Command: empty

## Controls
WASD / Arrow Keys = Move
Mouse = Aim
Left Click / Space = Shoot
P = Pause
R = Restart after Game Over
I = Instructions
ESC = Menu

## Customization
Easy, Normal and Hardcore change enemy spawn rate, enemy speed, collision damage and score multiplier.

## Lab Test Features
Animation, multimedia audio, user interaction, keyboard/mouse events, collision detection, score management, health, game states, restart, pause, increasing difficulty and meaningful customization.
